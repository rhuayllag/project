# Portal Web - Administración de Redes y Comunicaciones
### Instituto de Educación Superior "Honorio Delgado Espinoza"

Este proyecto es el portal web oficial de presentación para la carrera profesional técnica de **Administración de Redes y Comunicaciones** del I.E.S. Honorio Delgado Espinoza, ubicado en Arequipa, Perú.

---

## 📌 Descripción del Proyecto

La página web está diseñada para brindar información detallada a postulantes, estudiantes y la comunidad académica sobre la carrera. Ofrece una interfaz interactiva con secciones institucionales, módulos formativos, áreas de desempeño laboral y acceso directo al Aula Virtual.

---

## 📚 Estructura de Módulos Formativos

La carrera se organiza en 3 módulos o especialidades principales (duración total de 6 semestres / 3 años):

1. **Soporte Técnico de Tecnologías de la Información:** Fundamentos de TI, mantenimiento preventivo y correctivo de hardware/software, administración de sistemas operativos (Windows y Linux) y virtualización.
2. **Implementación de Redes y Servicios de Información:** Diseño de cableado estructurado, configuración de servidores (DNS, DHCP, FTP), desarrollo web y aplicaciones móviles.
3. **Administración de Redes y Gestión de la Seguridad:** Redes a nivel industrial, ciberseguridad, hacking ético, informática forense e Internet de las Cosas (IoT).

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica del sitio web.
- **CSS3:** Estilos personalizados (`principalstyles.css`) y diseño responsivo.
- **JavaScript:** Manejo del carrusel de imágenes, barra de navegación interactiva y lógica del cliente (`script.js`).
- **FontAwesome v6.4.0:** Iconografía profesional.
- **PHP:** Integración para el módulo de acceso al Aula Virtual (`AulaVirtual/login.php`).

---

## 🌐 Características Principales

- **Banner Interactivo / Slideshow:** Galería dinámica de bienvenida.
- **Perfil Profesional:** Información sobre las competencias del egresado.
- **Malla Curricular Visual:** Sección dedicada al plan de estudios de la carrera.
- **Mapa de Ubicación:** Integración con Google Maps para ubicar el instituto (C. Los Arces 202, Arequipa).
- **Acceso Directo:** Enlaces a Intranet y Portal Oficial Institucional.
